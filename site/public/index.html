          01 / How it works
          
        
          One request, a whole crew on it
          
      
          
      
          Tell a bot the job in plain words. It splits the work into steps, routes each step to Claude, Codex or Antigravity by the quota you have left, and brings every edit back as a local branch with its checks.

            06 / Questions
            
      
            Before you install
            
      
            More detail on routing, branches and limits is in the guide.
            
    
            
    
            
      
            
        Where does it run?
        
            On your Mac. Swarmaa keeps its task queue, shared memory and chat log locally, and its Claude, Codex and Antigravity workers run tasks in a sandbox there. There is no cloud computer.
            
      
            
      
            
        Will it push or deploy without me?
        
            No. Swarm workers never push, merge, deploy, send messages or make payments. Every code task runs in its own git worktree and comes back as a local branch with its diff, for you to review and merge.
            
      
            
      
            
        How does it choose an agent?
        
            By your routing rules and the quota each service has left. By default: Claude until 90% of its 5-hour or weekly window, then Codex until 95%, then Antigravity until 95% for reviews and edits. Name an agent when you want that one.
            
      
            
      
            
        Which agents does it work with?
        
            Claude Code, Codex and Antigravity run the work. Grok can connect over MCP as a front desk from your phone: it checks status and hands out tasks, but doesn't run code itself.
            
      
            
      
            
        How long can a task run?
        
            Up to 60 minutes. Ask “how is task 3511 going?” to check on one, or continue it with a new instruction; continuing adds commits to the same branch.
