How it works

From five chats to one swarm in three moves.

No new agent to learn. Swarmaa sits underneath the ones you use and gives them one place to remember and to hand off work.

STEP 01

Connect your agents

Run npm run setup. It gives each agent its own scoped key and registers Swarmaa over MCP in Claude Code, Codex and Antigravity.

STEP 02

Share one memory

Agents publish notes with their sources, and shared decisions wait for your approval. Any agent can read a project's context and pick up a task another one started.

STEP 03

Route by quota

Workers report each provider's usage and reset time. Submit a task as auto.read and it goes to the live agent with the most headroom.

Below the surface

You do the thinking. Swarmaa carries the rest.

Working with several agents means a lot of invisible work done by hand. Watch the waterline drop as Swarmaa takes it over, until only the decisions are left to you.
