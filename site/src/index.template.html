Every edit lands on a branch you own.

Each task runs in its own sandboxed worktree. Swarmaa commits the result to a local branch with the diff attached. You review and merge.

Open source · macOS

Every agent, one swarm.

  1. Download the Mac app and drag it to Applications.
  2. Open it and choose Set up Swarmaa on this Mac. It installs its own database and service; no terminal, no account.
  3. Paste the starter prompt it gives you into Claude Code, Codex or Antigravity.
